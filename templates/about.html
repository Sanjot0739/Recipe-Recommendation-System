Machine Learning

TF-IDF converts recipe text into numerical vectors and cosine similarity measures how closely recipes match a search or another recipe.

Recommendations

Users can search using recipe names or ingredients and receive relevant recipes and similar dishes.

Project Overview

RecipeAI is a Flask web application designed to make recipe discovery easier. The system processes recipe title and ingredient information and uses content-based similarity to rank relevant recipes.

The project demonstrates the practical use of Python, Flask, Pandas and Scikit-Learn in a machine-learning recommendation application.
